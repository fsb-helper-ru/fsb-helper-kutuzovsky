## Что помечено «предложение» или «не сверено»

- Подразделения ВК, ГРУ, ВМС, ССО, ГБР, ВПС, Академия/КМБ — только по неофициальному Уставу внутренней службы → «не сверено», **выключены по умолчанию** (DECISIONS ж); «Штаб» — предложение.
- Лестница званий (19 ступеней) — по неофициальному уставу → «не сверено»; закон о званиях среди законов Кутузовского не найден (GAP G-02).
- Коды рации («Зелёный/Жёлтый/Красный/Чёрный/Белый/Серый») — по неофициальному УКПС → во фразах помечены ⚠.
- Координаты всех меток, кроме главного КПП, — не опубликованы (GAP G-08) → 🟦 вводятся вручную.
- Часовой пояс графика базы в теме форума не указан → по умолчанию МСК, настраивается.
- Расхождения источников показаны в самих разделах пометкой «спорно»: C-03 (кнопки планшета шире закона), C-05 («Росгвардия»/«Национальная гвардия», в законе о ВС отдела нет), C-09 (лимит криминала 100/80/50), C-01 (подчинение МВД или Минобороны — в карточке «С кем взаимодействуем» даны обе нормы).

## Чего в 4.0.0 нет (честно)

- **Дистанционное управление справочником отделов из Центра управления** — не реализовано: справочник ведётся в программе (включить/выключить/переименовать/добавить, экспорт и импорт JSON), владелец может разослать JSON. Для управления с сайта нужен подписанный файл справочника и его загрузка оболочкой — предложение на 4.1 (DECISIONS л).
- **Командный пакет** (приказы по личному составу, график нарядов, учёт допусков) — выключен: роль `r` в ключе заложена, но пустая (DECISIONS б). Есть бланк «Приказ» и журнал смены.
- **Журнал караула как отдельный реестр постов** — используется общий «Журнал смены» и «Караул и пост»; список постов не редактируется (поле свободное).
- Дословные тексты правил форума после 25.10.2026 — только пересказ изменений (`rules_upd`); полные официальные тексты уставов — закрытый раздел форума (GAP G-04).
