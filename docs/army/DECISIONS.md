# DECISIONS.md — решения для владельца простыми словами (этап 1)

Владелец 07.11.2026 19:09: «делай сам автономно». Поэтому ниже — что я выбрала по умолчанию (всегда самый безопасный вариант) и как это изменить.

| № | Вопрос | Выбрано по умолчанию | Почему | Как изменить |
|---|---|---|---|---|
| а | Один ключ = одна фракция? | **Да.** Смена фракции = «Перевыпустить» в Центре: старый ключ отвязывается, выдаётся новый, в журнале аудита остаётся запись | Иначе невозможно доказать, какую фракцию видит игрок | Нельзя безопасно сделать иначе; оставить |
| б | Заложить ли в ключ роль «командный состав» (командный пакет) | **Поле `r` заложено, в 4.0.0 выключено** (всегда пустое; программа его читает, но ничего не включает) | Командный пакет (приказы, учёт личного состава) требует подтверждённых званий и отделов, которых в источниках нет | Когда появятся звания/отделы — отдельный этап: Центр ставит `r:'cmd'`, программа включает раздел «Командование» |
| в | Что делать с данными прежней фракции при смене ключа | **Хранить отдельно, не стирать.** Данные лежат под своим ключом хранения (`fsb_…@id` / `army_…@id`); при возврате ключа прежней фракции всё на месте | Потеря данных необратима; изоляция обеспечивается разными ключами хранения | В настройках есть «Сброс данных» — игрок может стереть сам |
| г | Где хранить исходники (GAPS D-01) | **Пока — рабочая папка + архив исходников владельцу файлом на каждом рубеже.** В ветку `army-module` публичного репозитория кладём только `docs/army/` | Создать приватный репозиторий из песочницы нельзя; публиковать весь код в публичный репозиторий без решения владельца не буду | Сказать «да, приватный» — дам пошаговую инструкцию (3 клика) и перенесу код |
| д | Чистить ли историю публичного репозитория от журналов 3.3 (D-02) | **Нет** (не трогаю) | Необратимо; старые ключи 3.3 не принимаются с 3.6.1 | Сказать «чисти» — объясню последствия и сделаю |
| е | Дословные тексты законов для Армии | **Берём из неофициального репозитория (как ФСБ-модуль), сверяем структуру с вики, подписываем «копия; официальная редакция — форум» и храним хэш** | Владелец копировать не может, браузер не подключён, прямой доступ к сайтам закрыт прокси | Подключить Chrome или прислать тексты — заменю на официальные с хэшем |
| ж | Звания и отделы | **Подтверждённые (караул, ВП, командование, Росгвардия) включены; остальные (ВК, ГРУ, ВМС, ССО, ГБР, ВПС, Академия, КМБ) и лестница званий — в справочнике со статусом «не проверено», ВЫКЛЮЧЕНЫ по умолчанию** | Правило «не выдумывать игровые правила» | Прислать скриншот планшета «Коллеги» — включу подтверждённые |
| з | Название программы для армейского игрока | Установщик и файлы остаются `FSB-Helper-Setup.exe` (цепочка обновлений); окно входа — нейтральное «Помощник · Кутузовский»; после входа окно называется «Армия-помощник» или «ФСБ-помощник» | Переименование файлов сломало бы автообновление старых версий | Можно переименовать установщик в следующих версиях |
| и | Экзамен Армии | 50 вопросов, 40 минут, 95 % = 48 из 50; банк ≥150; ФСБ без изменений (30/25/95) | Требование задания; время — пропорционально ФСБ (25 мин на 30) | Поменять константы в `packs/army/pack.js` |
| к | Публикация 4.0.0 | **Ничего не публикуется без «да».** Готовые файлы (установщик, SHA-256, Центр, version.json) отдаю файлами и жду «Загрузил» → «да» | Правило владельца 06.11 и задания | — |
| л | Справочник отделов «управляемый из Центра управления» | **В 4.0.0 — управляется в самой программе** (включить/выключить, переименовать, кто и когда утвердил, свои отделы, экспорт/импорт JSON). Дистанционного управления с сайта нет | Для управления с сайта нужен новый подписанный файл (`army_units.json`), его загрузка оболочкой и проверка подписи — отдельный контур с тестами; делать его «по-быстрому» в выпуск 4.0.0 рискованно | Сказать «да, нужно с сайта» — сделаю в 4.1: Центр подписывает справочник тем же ключом, оболочка проверяет подпись и отдаёт странице |
| м | Неподтверждённые отделы (ВК, ГРУ, ВМС, ССО, ГБР, ВПС, Академия) | **Показаны в справочнике со статусом «не сверено», но выключены**; включаются одной кнопкой | Правило «не выдумывать игровые факты» (ж), но и не прятать известное из неофициального устава | Включить в программе кнопкой «глаз» или прислать скриншот планшета — включу по умолчанию |
| н | График базы, лимиты, координаты | **Настраиваемые в программе**, у каждого значения дата и источник; изменённое помечается «изменено вами», кнопка «вернуть значения из темы» | Правила форума меняются; координаты в источниках не опубликованы | Владелец и игроки правят сами; при обновлении темы форума — пришлите текст, обновлю значения по умолчанию |
