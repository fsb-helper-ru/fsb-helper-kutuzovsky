# docs/army — операция «Армия», этап 0 (разведка, без кода)

Файлы:
- `ARMY_FACTS.md` — база фактов об Армии по 12 пунктам чек-листа, каждый факт с источником, датой и статусом ✅/⚠️/💡/❓.
- `CONFLICTS.md` — 18 расхождений между источниками (C-01…C-18) с указанием, что нужно от владельца.
- `GAPS.md` — пробелы G-01…G-13 с простыми шагами для владельца и решения D-01, D-02.
- `LESSONS.md` — опыт ФСБ-помощника: карта проекта, решения, история ошибок (P1–P28), негласные правила, чек-лист релиза, нерешённое N-01…N-08. Этапы 1–5 обязаны соблюдать раздел 7.
- `SOURCES.md` — журнал: какие страницы и файлы прочитаны, когда, чем, что сохранено.
- `raw/*.md` — пересказы прочитанных страниц по пунктам (не дословные тексты).

Порядок для следующей сессии: прочитать LESSONS.md → ARMY_FACTS.md → GAPS.md/CONFLICTS.md → этап 1 (план и архитектура, без кода),
дождавшись ответов владельца по G-01, G-04, G-05, G-06 и D-01.
