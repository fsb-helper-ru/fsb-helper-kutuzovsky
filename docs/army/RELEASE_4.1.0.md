# Выпуск 4.1.0 — что произойдёт, кого затронет, как откатить

Простыми словами, для владельца. Ничего из этого не запускается без твоего «да».

## Что в выпуске

- **Запись экрана и «повтор»** (Инструменты → «Запись экрана»): экран или окно игры со звуком в MP4 (H.264; WebM, если система не умеет). Alt+R — начать и остановить прямо в игре, в HUD горит «● ЗАПИСЬ» и время. «Повтор» держит последние 1–5 минут на диске, Alt+K — сохранить их файлом. Четыре уровня качества, микрофон и курсор по желанию. Файл пишется сразу на диск — память не растёт. Не мешает игре: программа только читает картинку экрана средствами Windows, как OBS.
- **«Спросить»** — помощник по законам: вопрос своими словами → ответ из статей, ситуаций, быстрых ответов и словаря программы, с цитатой и номером статьи. Это не нейросеть: ничего не выдумывает (цитаты дословные — проверяется тестом), работает без интернета, отвечает за доли секунды.
- **Оформление и удобство** (по аудиту, который ты видел в AUDIT_4.1.html): меню в одну строку с группой разделов модуля, подсказки и «О разделе» сами сворачиваются после двух показов, кнопка «Наверх», «ещё» у длинных подзаголовков, понятный порядок кнопок бланка, «Сохранить копию в файл» вместо «Экспорт», в Армии убраны внутренние коды источников, «Экономный режим графики» для слабых ПК, фон рисуется без тормозов при прокрутке.
- **Новый установщик**: своё окно с ходом установки и кнопкой «Запустить сейчас» вместо системных окон «Yes/No»; при первом запуске — короткое приветствие. Из установщика и удалятеля убраны приёмы, похожие на вредоносные (скрытые `taskkill` и «самоудаление через `cmd /c ping … & del`»): теперь программа сначала вежливо просит себя закрыть, а закрывает принудительно только если не ответила.
- **Ярлык** теперь называется «Помощник Кутузовский» (раньше «ФСБ-помощник», а в программе уже и Армия). Старый ярлык заменяется новым, а не дублируется.
- **Сайт**: короткая главная (в 2,7 раза короче на компьютере и в 2,3 раза на телефоне) и отдельные страницы — «Гайды», «Вопросы», «Безопасность», «Что нового»; шапка больше не ломается на 1280 px и на планшетах; все старые ссылки (`#army`, `#key`, `#install`, `#faq`…) продолжают работать.
- **Центр управления**: название «Центр управления · Помощник Кутузовский», вкладки помещаются на 1280 px. Логика ключей не менялась.

## Кого затронет и как

| Кто | Что увидит | Что делать |
|---|---|---|
| Игроки с программой 4.0.0 (и 3.4–3.6.1) | В течение ~часа после публикации: «Доступна версия 4.1.0 — нужна новая программа»; на Windows программа сама скачивает установщик с GitHub, сверяет SHA-256 и предлагает «Обновить сейчас» | Нажать «Обновить сейчас». Вход, ключ, данные и настройки сохраняются |
| Новые игроки | Скачивают установщик с сайта — новое окно установки | Как раньше |
| Ты (владелец) | Новый файл Центра управления (`FSB-Control-Center.html`); старый 4.0 тоже продолжит работать — формат ключей тот же | Заменить файл Центра (по желанию) |
| Выданные ключи (сейчас 6 пользователей) | Ничего: `lic.json`, `users.enc.json`, `inbox.json` переносятся из репозитория как есть в момент публикации | — |

Почему нужен установщик, а не быстрое обновление страниц: запись экрана живёт в самой программе (оболочке), её уровень поднят до 8. Поэтому в `version.json` стоит `minShell: 8` — программы 4.0.0 и старше получат «нужна новая программа» и скачают установщик сами (так же, как было с 3.6.1 → 4.0.0).

## Порядок публикации (3 шага, как в 4.0.0)

1. **Выпуск на GitHub (ты).** Открыть ссылку из `release_link.txt` (там уже тег `v4.1.0`, название и описание с SHA-256), перетащить `FSB-Helper-Setup.exe` (≈ 145 МБ), нажать «Publish release». Файл присылаю в .zip — его нужно распаковать перед загрузкой.
2. **Сайт (я, после твоего «да»).** `tools/deploy_when_ready.sh` ждёт, пока GitHub покажет выпуск с правильной суммой, забирает свежие ключи из репозитория, пересобирает сайт и публикует его одним коммитом в `main`.
3. **Проверка вживую (🟦 ты, 5 минут).** Открыть сайт — новая главная, «Скачать» ведёт на 4.1.0. На своей программе: дождаться «Доступна версия 4.1.0» → «Обновить сейчас» → после установки зайти в «Инструменты → Запись экрана», записать 10 секунд игры (Alt+R), открыть файл. Попробовать «Спросить».

## Как откатить

| Ситуация | Действие | Время |
|---|---|---|
| Сайт или обновление сломаны, выпуск ещё мало кто поставил | `git revert` коммита сайта и push — на сайте снова 4.0.0 (`version.json`, страницы и главная 4.0); программы 4.0.0 перестанут предлагать обновление | 5 минут |
| Выпуск v4.1.0 на GitHub с ошибкой | Удалить выпуск v4.1.0 → «последним» снова станет v4.0.0; затем откатить сайт (строка выше) | 5 минут |
| У кого-то проблема на 4.1.0 | Поставить установщик 4.0.0 (лежит в выпуске v4.0.0 на GitHub) поверх — данные и вход сохраняются | 2 минуты |
| Ключи | Откат не нужен: формат ключей и списка не менялся | — |

## Что проверено автоматически (подробно — EVIDENCE.md, E-111…E-120)

- **Один полный прогон на итоговых файлах: 53 набора из 53, ≈ 1 980 проверок** (страницы ФСБ и Армии, сайт, оболочка, настоящий Electron, установщик под Wine, живая связка с GitHub, удобство 4.0 → 4.1). Первый запуск сам нашёл 4 поломки — исправлены, всё пересобрано и проверено заново.
- **Намеренные поломки: 39 из 39 пойманы тестами** (запись, «Спросить», оформление, установщик, сайт, Центр, Армия, экзамен).
- **Обновление с настоящих 4.0.0 и 3.6.1 на точных файлах выпуска** — «нужна новая программа», условия автоскачивания с GitHub выполнены; 4.1.0 входит сама, данные целы, ключ Армии открывает Армию (33 проверки). Живой сайт: 6 твоих пользователей, список подписан, совместим (40 + 29 проверок).
- **Удобство (те же автопроверки, что в аудите), 4.0 → 4.1:** за краем окна 64 → 0, кнопки и поля без подписи 374 → 0, низкий контраст 489 → 269, маленькие кнопки 196 → 122, мелкий текст 9542 → 6874.
- **Запись экрана в настоящей программе** (виртуальный экран): MP4 H.264 + звук, WebM с длительностью, «повтор», HUD — 23 проверки.
- **Установщик под Wine**: установка, обновление поверх запущенной программы (вежливое закрытие), удаление «упрямой» программы, окно установщика — 16 + 6 проверок; в файле нет `taskkill` и «самоудаления через cmd».

## Что НЕ проверено (честно)

- **Запись на настоящем Windows с игрой** (кодирование видеокартой, звук игры через loopback, нагрузка на FPS) — в песочнице нет Windows и видеокарты. Проверено в настоящей программе Electron под виртуальным экраном (Linux): MP4 H.264 + Opus, WebM с длительностью, повтор отрезками, HUD, клавиши. 🟦 ты, шаг 3.
- **SmartScreen и антивирусы**: без платного сертификата подписи Windows всё равно покажет «Система Windows защитила ваш компьютер» для нового файла (пока у файла нет «репутации»). Что можно сделать бесплатно: отправить файл на проверку в Microsoft (https://www.microsoft.com/wdsi/filesubmission) как «ложное срабатывание», если Defender его задержит. Из установщика убраны приёмы, на которые обычно реагируют эвристики, — но гарантировать «ни один антивирус не ругнётся» без подписи нельзя.
- **Живой сайт GitHub Pages и канал ntfy** — из песочницы закрыты; проверены файлы в репозитории через GitHub API и цепочка на эмуляторах.
- **Карта Россия Онлайн** — не сделана в этом выпуске: картинку карты из игры скачать не удалось (Chrome не был подключён, прочие сайты закрыты прокси). Предлагаю 4.2: раздел «Карта», куда ты загружаешь свой снимок карты (клавиша M в игре), ставишь метки с иконками, описанием и поиском.
