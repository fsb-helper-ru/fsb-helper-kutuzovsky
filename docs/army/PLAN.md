Режим: автономный. Решения по умолчанию — самые безопасные (DECISIONS.md). Всё, что нельзя проверить из песочницы, помечается 🟦 с инструкцией владельцу.

## Этап 2 — ядро (код)
E2.1 `auth.js`: `FACTIONS = ['fsb','army']`, `keyHash(login,key,f)`, разбор `f/r/at/kid`, `acc.f`, `status()` код `faction`, `who().faction`; `requests.js`: `rf`; тесты RED→GREEN.
E2.2 Центр: модель пользователя `+f`; карточки выбора; значок; фильтр; статистика; `ST.audit`; перевыпуск; `buildLic`/`signTicket` с `f`; заявки `rf`; тексты сообщений.
E2.3 Страница: `PACK` в ядре; `src/pack_fsb.js`; вынос данных ФСБ (без изменения поведения); `packs/army/pack.js`; `build.py --pack`; `main.js`: выбор страницы и настроек по фракции, SHELL_API 7; `preload.js`: `account.faction`.
E2.4 `signin.html` нейтральный; заголовки окон по фракции.
E2.5 заявка `rf`; экран входа — выбор желаемой фракции (две карточки).
E2.6 отказ при неизвестной фракции.
E2.7 updater: `pages`, обе страницы, тесты.
E2.8 регресс ФСБ: все 48 наборов + скриншот-регрессия главных экранов (до/после) + снимок данных.

## Риски
1. Рефакторинг ядра ради `PACK` может изменить поведение ФСБ → смягчение: минимальные правки, скриншот-регрессия, полный регресс, байтовое сравнение данных.
2. Дословные тексты законов для Армии — только неофициальные копии (владелец копировать не может) → в интерфейсе каждая такая копия подписана «копия, структура сверена с вики <дата>; официальная редакция — форум»; GAPS G-04/G-05 остаются открытыми.
3. Звания/отделы не подтверждены → справочник настраиваемый, непроверенное выключено.
4. Старая программа 3.6.1 + армейский ключ → «ключ не подходит» без объяснения про фракцию → смягчение: `version.json` minShell 7 обновит программу раньше, чем владелец выдаст первый армейский ключ; в сообщении Центра для армейского ключа — «нужна версия 4.0.0».
5. Размер страницы Армии (вторая страница ≈ +1,5 МБ) — проверить время запуска (perf.js).
6. Публикация: сайт меняется только с «да».
