# PARITY.md — функция ФСБ → аналог для Армии (этап 1)

Объём: S — до 2 ч, M — до полудня, L — больше. «Ядро» — код общий, меняются только данные пакета.

| Функция ФСБ (маршрут) | Аналог для Армии | Объём | Особенности |
|---|---|---|---|
| Главная `home` (приветствие, «что сделать сейчас», быстрые действия, живые счётчики) | **A. Смена**: начало/конец службы, текущий пост и отдел, таймеры событий базы, быстрые доклады, заметки | M | ядро dash.js + данные пакета; виджет «ближайшее событие базы» новый |
| Ситуации `scn` (27, по шагам, привязка к статьям) | **≥27 ситуаций Армии**: КПП и доступ (ст. 15–18), караул (19), задержание и передача (25–26, ПГО 6.2), сила (30), преследование (29), выход за территорию (28), ВП/ЧП (ФКЗ), нападение на базу (ПБ-К, ПФ), поставки (ППП), похищение военного (ПОП), заложники (ПОП 5.5), оружие/склад (20), техника (21), съёмка (22), военная полиция (23–24), дисциплина/приказ (13, 27), взаимодействие (32), рапорт на повышение (ПГО 1.13/1.15), перевод (2.8–2.10), ЧС-ОПГ (ПГО 7.5), видеофиксация (7.4) | L | формат шагов ядра `[тип, текст]` с `[[doc:art]]`; проверяется тестом I16 |
| «Как не вылететь» `rules` (наказания ПГО) | то же для Армии: ПГО разд. 1, 6, 7 + правила Форта/поставок/ВП с наказаниями | S | ядро; фильтр по разделам ПГО из пакета |
| Законы `laws` (19 документов, группы, редакции, «свои документы») | **K**: ≥25 документов Кутузовского + форумные правила; группы: «Армия», «Режимы», «Правила сервера», «Кодексы», «Прочее»; провенанс и статус «копия/пересказ»; флажки расхождений (CONFLICTS) | M | laws2.js параметризуется `PACK.lawGroups`; новый бейдж `prov` |
| «Кто за что отвечает» `who` (подследственность Ф/Р/В/С) | **I. Взаимодействие**: матрица «с кем и как» (ФСБ, МВД, ГИБДД, СК, прокуратура, суд, Правительство) по ст. 26, 29, 32 и ПГО разд. 2 | M | отдельный вид пакета (данные `PACK.interact`) |
| «УК: шпаргалка» `uk` (буквы подследственности) | **Матрица «игра — закон — нельзя»** (C-03): для каждого игрового действия (наручники, обыск, розыск, штраф…) — когда законно для военного | M | новый вид пакета |
| Таймер задержания `tools/det` (процессуальный час, прокурор, СК) | **D. Задержание и передача**: таймер с шагами: основание → видео → права → доставка/передача ФСБ/МВД → доклад; без прокурорских веток | M | ядро tools2/ui_views3 параметризуется `PACK.det` (шаги/чек-лист) |
| Бланки `blanks` (12 типов, печати, PNG/PDF) | **J. ≥12 бланков**: доклад о заступлении/смене караула, о происшествии, о задержании (с передачей), о нарушении режима (ст. 18), о применении силы (ст. 30), о нападении на базу, о доставке поставки, о ЧС/ВП, рапорт на повышение + отчёт о работе, объяснительная, приказ, пропуск на территорию | L | движок общий; шаблоны `BK` пакета; печати «ВС РО» (свои, игровые), шапка «ВООРУЖЁННЫЕ СИЛЫ РО» |
| Отыгровки и слоты `tools/binder` | те же (ядро), стартовые наборы Армии: КПП, караул, задержание, поставка | S | данные пакета |
| Фразы `tools/phrases` | **P**: требования на КПП, доклады в рацию (коды — только после подтверждения, иначе «предложение»), права задержанному, передача ФСБ/МВД, ВП | M | данные пакета; формат команд чата — как в ФСБ |
| Дежурство `tools/duty` (пост, напоминания) | **B. Караул и посты**: реестр постов (настраиваемый), заступление/сдача, чек-лист, журнал караула, напоминание о докладе каждые N мин | M | ядро duty + расширение пакета (посты) |
| Таймеры `tools/timers` | те же + предустановки: нападение на базу (график), час отдыха, окно поставок, безопасный час, ВП 12 ч, заложники 30 мин | S | данные пакета, конфигурация с датой |
| Рапорты и шаблоны `tools/docs` | то же (ядро), шаблоны Армии | S | данные |
| Журнал смены `tools/cases` | **O. Журнал**: смены, посты, происшествия, задержания, применение силы, доклады; сводка для доклада | S | ядро; поля пакета |
| Счётчики смены `tools/counters` | то же: проверки на КПП, досмотры, задержания/передачи, доклады, выезды | S | данные |
| Калькулятор срока `tools/kpz` | **не нужен** (ВС не назначают наказания — ст. 25 п. 3); вместо него «Светофор силы» **E** | M | новый вид пакета |
| Окно поверх игры `tools/overlay` | то же (ядро), тема Армии, свои быстрые чипы | S | тема |
| Учёба `learn/*` (первые шаги, уроки, тест, словарь, быстрые ответы) | **L**: путь Новобранец → Караульный → Военная полиция → Командир (уроки по статьям), экзамен 50/95 %, банк ≥150, словарь (КПП, караул, ВП, Форт, авианосец, матовозка, коды…), быстрые ответы | L | ядро learn2/quiz2 с `PACK.exam`; данные пакета |
| Избранное, история, настройки, о программе | те же (ядро) | S | тексты пакета |
| Навигатор (ФСБ: точки в ситуациях/дашборде) | **N**: метки (главный КПП ✅, остальные 🟦 «уточнить в игре»), пункты передачи (МВД, ФСБ — координаты МВД ✅), фильтры | M | данные с пометками |
| Диагностика (о программе: версия, лицензия) | **R**: + фракция, статус ключа, версия контента, провенанс законов | S | ядро |
| Центр управления (пользователи, заявки, публикация) | + фракция: карточки, значки, фильтр, статистика, аудит, перевыпуск, `rf` | M | control.src.html |
| Сайт | + раздел «Армия», мелочи | S | site_page.py |
| Командный пакет **M** | **не в 4.0.0** (поле роли зарезервировано) | — | DECISIONS (б) |
