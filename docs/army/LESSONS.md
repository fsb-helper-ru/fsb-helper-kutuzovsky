Порядок сборки и выпуска (`file:AUDIT_361.md` этап 5–6; `file:tools/deploy_when_ready.sh`):
1. `python3 tools/build.py` (file) и `python3 tools/build.py shell/app.html --mode native --strict` → содержимое установщика = исходникам (проверка 13/13 файлов).
2. `tools/build_control.py` → Центр; `tools/pack_win.sh` → установщик; sha256 + размер → `release/release_link.txt`.
3. Владелец сам загружает установщик в GitHub Release и пишет «Загрузил» (API выпусков из песочницы закрыт).
4. Только после его «да»: `tools/make_site.py` → коммит в main (сайт + подписанный `version.json`) → GitHub Pages выкладывает → проверка `gh api .../actions/runs`.
5. Старые версии получают `version.json`, проверяют подпись/sha/minShell и обновляются сами; при неудаче — откат.

Публичный репозиторий содержит **только сайт** (27 файлов: `index.html`, `lic.json`, `pulse.json`, `inbox.json`, `version.json`,
`users.enc.json`, `app-3.6.1.html`, картинки, шрифты) — `git ls-files` 07.11.2026. Исходники программы в репозитории **отсутствуют**
(см. Нерешённое N-01).

## 2. Принятые решения и почему

| Решение | Почему | Источник |
|---|---|---|
| Ключ — 16 знаков из алфавита без O/0/I/1 (`23456789ABCDEFGHJKLMNPQRSTUVWXYZ`), 80 бит, `crypto.randomBytes`; привязан к логину (`keyHash = sha256('FSB3K|login|key')`) | Защита от опечаток и от чужого ключа; проверка без интернета | `CHANGELOG:3.3.0, 3.4.0`; `file:shell/lib/auth.js` |
| Список доступа `lic.json` подписан Ed25519 (`{p: JSON, s: подпись}`; `p` = `{app, kind:'lic', v:3, seq, ts, users[]…}`); программа принимает только подпись владельца; чужая подпись/повтор старого seq отвергаются | «Админ-действие без серверной проверки роли» (инвариант I10) в архитектуре без сервера = подпись владельца | `file:PROGRESS.md` (Архитектура), `file:shell/lib/auth.js`, `EV:E-041` |
| Пропуск (`kind:'tkt'`) к ключу по заявке: действует, пока `seq` пропуска > `seq` списка, ≤7 дней | Ключ работает сразу, даже если GitHub ещё не выложил сайт (минуты) | `AUDIT:P2`, `CHANGELOG:3.6.1` |
| Заявка на ключ шифруется к владельцу (X25519 + AES-256-GCM) и идёт через ntfy; ответ — в быструю тему `fsbr-…`; запасной путь — `inbox.json` на сайте | Прямого сервера нет; ntfy — бесплатный канал; шифрование — чтобы ник и ключ не читались посторонними | `file:shell/lib/requests.js`, `AUDIT:P2` |
| Пароль scrypt; смена пароля без ключа; «Забыли пароль?» = логин + тот же ключ (аккаунт сохраняется) | Пользователи забывали пароль и теряли данные | `CHANGELOG:3.6.0` |
| Опрос сайта каждые 30–60 с; офлайн ≤24 ч | Отзыв ключа срабатывает за минуту, но интернет-сбой не выбивает | `CHANGELOG:3.4.0`, `file:shell/lib/auth.js` |
| Обновления: `version.json` с подписью ключом обновлений, sha256 + размер установщика, `minShell`, тихая установка в свёрнутом окне, откат при неудачном старте | 3.3 → 3.4 обновление ломалось (не могла скачать), 3.6.0 «откатывалась сама» | `CHANGELOG:3.4.0, 3.6.0`; `file:shell/lib/updater.js` |
| Хранение: `auth.json`, `settings.json`, `requests.json` — атомарно с `.bak`; данные игрока — `localStorage` страницы с копией `…_bad` при повреждении; `KEY = fsb_helper_kutuzovsky_v2@<accountId>` (свои данные у каждого аккаунта) | Потери аккаунта при внезапном выключении/полном диске (P21–P23) | `EV:E-001..E-003`, `file:src/engine.js` |
| Законы вшиты в HTML при сборке из `out/laws.json`; у каждого документа подпись редакции | Работа без интернета; редакция видна пользователю | `file:tools/build.py`, `file:tools/build_data.py` |
| Панель поверх игры: по умолчанию **с фокусом** (с 3.6.1), сквозной режим Alt+L выключается при обновлении один раз, подсказка при открытии в сквозном режиме | В 3.4 панель сделали «без фокуса» — над GTA щелчки не доходили (P5, P20) | `AUDIT:P5, P20`, `CHANGELOG:3.6.1` |
| Ввод в игру — только через буфер обмена; никаких нажатий клавиш в игру, никаких хуков | Правило владельца и безопасность аккаунта игрока | `owner` (правила сессии, зафиксированы в журнале 3.6.1) |
| Экзамен: 30 вопросов / 25 мин / сдан от 95 % без округления (`examPassed = n>0 && ok*100 >= 95*n`); уход в законы/другое окно аннулирует попытку; новая — с новыми вопросами | Владелец просил «сложнее»; обнаружено округление 94,7 % → «сдан» (P26) | `AUDIT:P7, P8, P26`, `EV:E-010, E-011` |

| Сайт — только HTML+CSS (CSP `default-src 'none'`), контент из `site_page.py` (мини-гайды, FAQ 25 вопросов) | Безопасность и простота; владелец просил «капитально обновить сайт» 06.11 23:3x | `git:b34a58c`, `file:tools/site_page.py` |
| Доказательства: PASS только с повторяемым автотестом, RED→GREEN, мутациями и журналом EVIDENCE.md; независимый проверяющий со свежим контекстом | Требование владельца ZERO_DEFECT_PROMPT_v3 (21:08 06.11) | `file:EVIDENCE.md` (правила в шапке), `file:PROGRESS.md` |
