# Выпуск 4.0.0 — что произойдёт, кого затронет, как откатить

Простыми словами, для владельца. Ничего из этого не запускается без твоего «да».

## Что в выпуске

- **Одна программа — два модуля.** ФСБ и Армия в одном установщике. Какой модуль откроется, решает ключ (поле «фракция» в записи ключа, подписанное тобой через Центр управления). Все существующие ключи — ФСБ.
- **Армия**: 40 законов и правил с источниками, 34 ситуации, 13 бланков, уроки, экзамен 50 вопросов (48 из 50), светофор силы, «с кем взаимодействуем», «игра — закон — нельзя», база и поставки с таймерами, справочник отделов, навигатор. Своё оформление (олива, латунь).
- **ФСБ** — без изменений в поведении и внешнем виде (проверено по 44 экранам: 0 пикселей разницы), только новый текст «Что нового» и исправление: раздел по прямой ссылке открывается сразу при запуске.
- **Экран входа** общий, в заявке на ключ можно отметить модуль. **Центр управления** показывает фракцию карточками, журнал аудита, перевыпуск ключа с переводом в другую фракцию.
- **Сайт**: раздел «Армия», ссылка на знаке ведёт в начало, «21 печать и штамп», ник Discord выделяется одним щелчком; ошибка «дубликат заголовка FAQ» в текущей разметке не воспроизводится (один заголовок «Вопросы и ответы») — если увидишь её на живом сайте, пришли скриншот.

## Кого затронет и как

| Кто | Что увидит | Что делать |
|---|---|---|
| Игроки с программой 3.4–3.6.1 | В течение ~часа после публикации: «Доступна версия 4.0.0 — нужен установщик», программа сама скачивает и проверяет установщик (SHA-256), ставит его; после установки входит сама, аккаунт, ключ и данные на месте. Это проверено на настоящей выпущенной 3.6.1 (E-108) | Ничего. Если установщик не скачался — кнопка «Скачать» на сайте |
| Игроки ФСБ после обновления | Та же программа, тот же модуль ФСБ; на экране входа новое общее название | Ничего |
| Будущие игроки Армии | Скачивают ту же программу, в заявке отмечают «Армия»; ты выдаёшь ключ с карточкой «Армия» в Центре | Ты: Центр управления → заявка → карточка «Армия» → ключ |
| Ты (владелец) | Новый Центр управления (файл `FSB-Control-Center.html`) — старый 3.6.1 новые поля не понимает | Заменить файл Центра на новый (отдам файлом); старый не использовать |
| Чужие копии страницы (HTML без программы) | Не затронуты: HTML-версия не публикуется с 3.4 | — |

Что **не** меняется: ключи, пароли, список пользователей (lic.json переносится из репозитория как есть), адрес сайта, имена файлов (`FSB-Helper-Setup.exe`, `FSB-Helper.exe`, папка установки) — поэтому обновление поверх проходит без повторной установки вручную.

## Порядок публикации (3 шага, как в 3.6.1)

1. **Выпуск на GitHub.** Я пришлю файл `FSB-Helper-Setup.exe` (151 МБ) и готовую ссылку «новый выпуск» (`release/release_link.txt`: тег `v4.0.0`, название, описание, SHA-256 уже вписаны). Ты: открыть ссылку → перетащить файл → «Publish release». Напиши мне «Загрузил».
2. **Сайт.** После твоего «да» я запускаю `tools/deploy_when_ready.sh`: он дожидается, пока GitHub покажет выпуск с правильной суммой, забирает свежий `main` (там твои выданные ключи), пересобирает сайт с `version.json` (minShell 7, обе страницы) и отправляет коммит в `main`. Это — «push в основную ветку», поэтому только после твоего «да».
3. **Проверка вживую (🟦 ты).** Открыть сайт, убедиться, что есть раздел «Армия» и ссылка «Скачать» ведёт на 4.0.0; на своей программе 3.6.1 дождаться предложения обновиться; после обновления войти; в Центре управления выдать тестовый ключ Армии тестовому логину и проверить, что программа открывает модуль «Армия».

## Как откатить

| Ситуация | Действие | Время |
|---|---|---|
| Сайт/обновление сломаны, выпуск ещё не поставили | `git revert` коммита сайта в репозитории и push — `version.json` снова 3.6.1 (`app-3.6.1.html` вернётся из истории). Программы 3.6.1 перестанут видеть 4.0.0 | 5 минут |
| Кто-то уже поставил 4.0.0 и у него проблема | Откат одной программы: установить `FSB-Helper-Setup.exe` от 3.6.1 (лежит в выпуске v3.6.1 на GitHub и у меня в `release/FSB-Helper-Setup-3.6.1.exe.bak`) поверх — аккаунт и данные сохраняются (форматы данных не менялись: новое поле `packState` просто пустое у ФСБ) | 3 минуты на человека |
| Нужно отозвать армейский ключ | Центр управления → пользователь → «Отключить» или удалить — как раньше | 1 минута |
| Центр управления новый не нравится | Старый Центр 3.6.1 продолжает работать с ФСБ-ключами (новые поля f/at/kid он не трогает, но и не пишет; армейские записи он покажет как обычные) — но выдавать армейские ключи он не умеет | — |

Откат **не** понадобится из-за ключей: записи 4.0.0 в `lic.json` совместимы с 3.6.1 (поле `f` старые программы игнорируют), армейские записи для них просто «чужие ключи».

## Что проверено автоматически (кратко; подробно — EVIDENCE.md)

- Полный регресс ФСБ (страница 23 набора, оболочка 9 наборов, Electron 8 сценариев) — один прогон на финальной сборке, как ты разрешил.
- Новые тесты Армии: контент 82, экзамен 32, изоляция 38, выбор страницы по ключу в Electron 30 — зелёные в финальном прогоне на итоговой сборке (и в более ранних прогонах при разработке); 8 намеренных поломок (мутаций) — все пойманы тестами.
- Обновление с настоящей 3.6.1 на 4.0.0 — 19 проверок; точные файлы выпуска (установщик, страницы, подписанные version.json и lic.json) сквозь настоящую 3.6.1 → 4.0.0 → ключ Армии → следующее обновление — 22 проверки.
- Связка «сайт на GitHub ↔ ключи ↔ программа»: то, что сейчас лежит в репозитории (lic.json с твоими 5 ключами, pulse, version.json 3.6.1, выпуск v3.6.1, inbox, users.enc), проверено теми же библиотеками, что внутри программы — 37 + 27 проверок, расхождений нет; новые файлы 4.0.0 совпадают по подписям и суммам с установщиком. Один раз поймал, что копия репозитория в песочнице отстала от твоих ночных ключей — исправлено (перед сборкой сайта всегда свежий `main`).
- Оформление ФСБ — 0,0 % различий на 44 экранах; контраст Армии ≥ 4,5:1 (кроме одного приближения аудита, объяснено).

## Что НЕ проверено (честно)

- Живой сайт GitHub Pages, живой канал ntfy, настоящая Windows — из песочницы недоступны (🟦 шаг 3 выше).
- Справочник отделов управляется в программе, не с сайта (DECISIONS л) — на 4.1 по твоему «да».
- Официальные тексты уставов, названия отделов, звания, координаты — в открытых источниках нет; в программе помечены «не сверено»/🟦 и настраиваются.
- Независимая проверка в новой сессии (этап 6) — после твоего решения по публикации, с этим файлом и EVIDENCE.md на входе.
