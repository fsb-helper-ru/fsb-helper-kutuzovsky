# DESIGN.md — оформление модуля «Армия» (этап 4, 07.11.2026)

Задание: тёмный хаки/олива + графит, латунные акценты, песок; цифровой камуфляж — только едва заметной текстурой; прямые углы, шевроны, звёзды, погон; свои значки; **оформление ФСБ не меняется** (скриншотная регрессия); читаемость оверлея (контраст ≥ 4.5:1).

## Как устроено

Общие стили ядра (`src/style*.css`) не тронуты (единственная правка — нейтральный комментарий в шапке `style.css`). Тема Армии — отдельный файл `packs/army/theme.css`, который `tools/build.py` подключает **только** в сборку `--pack army` после общих стилей и переопределяет токены и углы. В сборке ФСБ этого файла нет (проверка `t_isolation.js`: `--camo:` есть только у Армии).

## Элементы

- **Знак** — двойной шеврон (`LUCIDE["army-logo"]`, подмена `ICON_ALIAS.logo` в `views.js`), на тёмной плашке с латунной рамкой; в заголовке главной — шеврон со звездой (`PACK.heroMark`). Герб и печати бланков — общий игровой герб ядра (щит, меч, звёзды, лавр — не герб РФ и не ведомственный); печать дежурного — «КАРАУЛ».
- **Погон** — полоса с двумя просветами над заголовком каждого раздела (`.page > h1::before`), 84×4 px латунь.
- **Активный пункт меню** — прямоугольный латунный маркер без скругления (`.nav a.on::before`); название в шапке — капителью с разрядкой.
- **Светофор силы** — три колонки с толстой левой кромкой зелёный/жёлтый/красный, заголовки капителью.
- **Матрица** — таблица с тонкими линейками (`.mx`), заголовки капителью.
- **Справочник подразделений** — карточки со статусными тегами (`подтверждено` зелёный, `не сверено` жёлтый, `предложение` латунь); выключенные — пунктирная рамка.
- Типографика — системная, как в ядре (`Inter` / `Segoe UI` / system-ui); без новых шрифтов, чтобы не раздувать файл и не менять ФСБ.
