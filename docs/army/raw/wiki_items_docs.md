## Служебные удостоверения — https://russiaonline.wiki/wiki/items/sluzhebnye-udostovereniya (опубл. 08.08.2026, изм. 06.11.2026)
Фракции: МВД, ФСБ, ВС, Правительство, Минздрав, СМИ. Разворот: слева — фото, ведомство, имя и фамилия, Static ID, дата получения; справа — полное название структуры, должность, разрешительная формулировка, подпись руководителя, печать.
ВС: в примере должность «Генерал-полковник» (поля «звание» отдельно нет); формулировка силовых ведомств — право постоянно носить и хранить табельное огнестрельное оружие и спецсредства; подпись — руководитель структуры (страница называет примеры: начальник МВД, министр обороны, президент; для карточки ВС подпись министра обороны НЕ подтверждена прямо). МВД: «Оперуполномоченный», те же права. Правительство: «Главный прокурор», только спецсредства. Не описано: выдача, изъятие при задержании, подделка.
→ Для модуля: бланк «Удостоверение ВС» — поля ✅; подпись «Министр обороны» — ⚠️ (raw/wiki_org_vs.md говорит «подпись Министр обороны», эта страница — осторожнее) → показать владельцу скриншот из игры.

## Форма госфракций — https://russiaonline.wiki/wiki/items/formy-gosfraktsiy (опубл. 07.08.2026, изм. 07.11.2026)
Используется в МВД, ГИБДД, Минздраве, ВС. Про форму ВС — только общее описание видео («армейские будни, военная техника, подготовка к масштабным событиям»); цвета/камуфляж/погоны/шевроны НЕ описаны. Комплектность по званиям, выдача, кастомизация — официально не описаны. Разработчики: «униформа для соответствующих профессий обязательно будет».
Другие источники о форме: raw/wiki_org_vs.md — «полевой комплект в цифровом камуфляже с кепи» (вики по скриншоту); raw/wiki_ro_armiya.md — в гардеробе комплекты «Национальной гвардии» (так на странице — ⚠️ расхождение в названии).
→ Для темы «Армия» в приложении: цифровой камуфляж как лёгкая текстура подтверждён скриншотами вики ✅; конкретные цвета — 💡 предложение дизайнера, не игровой факт.
