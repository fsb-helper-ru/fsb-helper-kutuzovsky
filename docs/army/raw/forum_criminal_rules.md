## Тема «Правила криминальных организаций» (первое сообщение 25.07.2026, ред. 25.09.2026)
Правил о взаимодействии с госструктурами/Армией/базой/перехватом/военным положением НЕТ. Для Армии важны только:
- п. 2.4 — на респауне ОПГ разрешено открывать огонь по сотрудникам госорганизаций без предупреждения (⚠️ для армейских выездов на территорию ОПГ; п. 7 правил госорганизаций запрещает силовикам находиться на территории ОПГ).
- п. 2.2 — посещение территории ОПГ группой ≥10 только для дипломатии/торговли (это для ОПГ, не для госов).
- п. 3.1 — захваты территорий ОПГ 16:00–23:00 МСК; п. 3.6 видео ≥720p, 72 ч; п. 3.13 — за 60 мин до капта нельзя.
- п. 1.3 — видео дипломатии хранить 72 ч (сравни: у силовиков 48 ч, 480p — п. 7 правил госорганизаций).
Остальные пункты (1.1–1.8 общие, 2.1–2.5 территории, 3.1–3.13 захват, 4.1–4.11 RP-стрела) — внутренние правила ОПГ, в модуль «Армия» не входят; при необходимости — только как справка «что может ОПГ» в ситуациях «нападение на базу».
