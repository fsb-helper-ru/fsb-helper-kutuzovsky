## Что сделано на этапах 2–4 (простыми словами)

1. **Ключ решает модуль.** В записи ключа есть поле «фракция» (подписано владельцем) и оно же зашито в хэш ключа. Старые ключи = ФСБ. Армейский ключ в старой программе 3.6.1 «не подходит» (честный отказ). Неизвестная фракция — вход закрыт с причиной.
2. **Центр управления** показывает фракцию карточками ФСБ/Армия, бейджи, фильтр, статистику, журнал аудита (хранится только в зашифрованной копии), перевыпуск ключа с переводом фракции, желаемый модуль из заявки (владелец решает сам).
3. **Одна программа — две страницы.** Оболочка открывает `app.html` (ФСБ) или `app_army.html` (Армия) по фракции ключа; у каждой — свой файл настроек, свой ключ хранения данных, своё название окна. Обновление приносит обе страницы сразу (`version.json → pages`), иначе — «нужен установщик».
4. **Полная изоляция.** В сборке Армии нет кода и данных ФСБ (и наоборот): маркеры пакетов, меню, инструменты, палитра, поиск, горячие клавиши, маршруты, хранилище, резервные копии (копия другого модуля не загружается).
5. **Контент Армии** — см. `CONTENT.md`: каждая ссылка проверена, у каждого текста закона источник и хэш, экзамен 50 вопросов, 48 из 50 — сдан, 47 — нет.
6. **Оформление** — олива/графит/латунь, едва заметный камуфляж, прямые углы, шеврон; ФСБ не изменилась ни на пиксель на 44 экранах.
