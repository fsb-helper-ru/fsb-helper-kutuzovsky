Windows или браузер ругаются? Это нормально

У «Регламента» нет платной цифровой подписи Microsoft — она стоит десятки тысяч рублей в год. Без неё Windows и браузеры не знают издателя и предупреждают о любой новой программе. Предупреждение не значит, что нашли вирус: это значит «мы не знаем, кто это сделал».

Почему можно доверять. Программа ставится в вашу папку пользователя без прав администратора, не трогает игру (ничего не нажимает за вас и не встраивается в неё), в интернет ходит только на сайт проекта (GitHub) и в канал заявок на ключ. Перед запуском можно сверить контрольную сумму файла с SHA256SUMS.txt — подробнее на странице «Безопасность».

1. Браузер не даёт скачать файл

Edge, Chrome или Яндекс Браузер пишут, что файл «обычно не скачивают» или «может быть опасен». Так браузер реагирует на редкие файлы без подписи.

  1. Наведите на файл в загрузках и нажмите «…» (три точки)

    Загрузки
    !FSB-Helper-Setup.exe обычно не скачивается. Перед открытием убедитесь, что доверяете файлу.
    Удалить…

  2. Выберите «Сохранить»

    Загрузки
    Сохранить
    Сообщить, что файл безопасен
    Подробнее

  3. Появится окно с кнопкой «Удалить». Рядом с ней — стрелка ▾: нажмите её и выберите «Всё равно сохранить»

    Убедитесь, что вы доверяете файлу
    Убедитесь, что вы доверяете файлу FSB-Helper-Setup.exe, прежде чем открывать его.
    Удалить▾
    Всё равно сохранить

    В Chrome то же самое: стрелка или «⋮» у файла → «Сохранить» / «Скачать небезопасный файл». Надписи в разных версиях браузеров немного отличаются — ищите «Сохранить» и «Всё равно».

2. Синее окно «Система Windows защитила ваш компьютер»

Это фильтр SmartScreen в Microsoft Defender. Он предупреждает о программах, которые ещё мало кто запускал.

  1. Нажмите «Подробнее»

    Фильтр SmartScreen в Microsoft Defender предотвратил запуск неопознанного приложения, которое может подвергнуть ваш компьютер риску.

  2. Появится кнопка «Выполнить в любом случае» — нажмите её

    Microsoft Defender SmartScreen

    Система Windows защитила ваш компьютер

    Приложение: FSB-Helper-Setup.exe
    Издатель: Неизвестный издатель

    «Неизвестный издатель» — как раз из-за отсутствия платной подписи. Дальше откроется установщик «Регламента».

3. «Интеллектуальное управление приложениями» заблокировало установку

В новой Windows 11 есть защита «Интеллектуальное управление приложениями» (Smart App Control). Она блокирует любые программы без подписи — и кнопки «Выполнить в любом случае» у неё нет. Если вы видите сообщение, что приложение заблокировано этой защитой, установить программу можно только после её выключения.

  1. Откройте «Безопасность Windows»

    Пуск → Параметры → Конфиденциальность и защита → Безопасность Windows → Управление приложениями и браузером.

  2. Нажмите «Параметры интеллектуального управления приложениями» и выберите «Выкл.»

    Безопасность Windows
    Управление приложениями и браузером › Интеллектуальное управление приложениями


    ◉ Выкл.

  3. Запустите установщик ещё раз

    Теперь сработает обычное предупреждение SmartScreen — см. шаг 2.

Честно о последствиях. Это защита Windows для всех программ без подписи, а не только для нашей. В некоторых версиях Windows включить её обратно можно только после сброса или переустановки системы. Microsoft Defender (обычный антивирус) при этом продолжает работать.

4. После установки

Программа появится на рабочем столе и в меню «Пуск» как «Регламент». Откройте её, во вкладке «Первый вход» введите логин и ключ, придумайте пароль. Нет ключа — нажмите «Получить ключ»: выберите сервер, фракцию и срок, укажите ник из игры и номер заказа Playerok. Подробнее — как купить ключ.
